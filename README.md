# NHR RUN 러너 테스트

2026 NHR RUN 사전 유형 테스트 사이트예요.
첫 화면 → 러너 등록 → 10문항 → 러너 유형 결과 → 러너 카드 이미지 저장 순서로 진행돼요.

## 어디를 고치면 뭐가 바뀌나요?

| 바꾸고 싶은 것 | 고칠 파일 |
| --- | --- |
| 선택지 문구, 어떤 선택지가 어떤 유형인지 | `data.js` 의 `QUESTIONS` |
| 결과 화면 설명, 완주 메시지, 해시태그, 유형 색 | `data.js` 의 `TYPES` |
| 캐릭터·리본 위치와 크기 | `data.js` (x, y, w 값) |
| 색, 글자 크기, 여백, 애니메이션 | `style.css` |
| 등록 화면 안내 문구, 버튼 문구 | `index.html` |
| 화면 넘김, 점수 계산, 카드 이미지 | `app.js` |
| 캐릭터·장식 그림 | `assets/characters/`, `assets/deco/` |

- 좌표(x, y, w)는 피그마 프레임(가로 1440px) 기준 px 값이에요.
- 결과는 가장 많이 고른 유형으로 정해지고, 동점이면 마지막에 고른 유형이 나와요.

## 노도 글자(제목·질문·유형 이름)는 그림이에요

제목, 질문, 유형 이름, 첫 화면 버튼 글자는 산돌 노도 글자를 그림(SVG)으로 바꿔 넣었어요.
파일은 `assets/text/` 에 있어요 (`q1.svg` ~ `q10.svg`, `S.svg` 등).

이 문구를 바꾸려면:
1. 피그마에서 해당 텍스트 레이어를 고칩니다.
2. 레이어를 선택하고 오른쪽 아래 Export에서 **SVG**로 내보냅니다.
3. `assets/text/` 의 같은 이름 파일을 새 파일로 바꿉니다.
4. `data.js` 맨 위 `TEXT_SIZE` 의 [가로, 세로] 값을 새 SVG 크기로 맞춥니다.
5. `data.js` 의 `q:` 문장도 같이 고쳐주세요 (화면 낭독기와 접근성용).

## ChatGPT 같은 AI로 고치기

- **파일 하나씩:** 고칠 파일(예: `data.js`) 내용을 복사해서 AI에게 붙여넣고 수정을 요청한 뒤, 결과를 GitHub 웹에서 연필 버튼으로 붙여넣고 저장하세요.
- **저장소 연결:** ChatGPT의 GitHub 연결 기능(Codex 등)으로 이 저장소를 연결하면, AI가 직접 파일을 고쳐 변경 요청(Pull Request)을 만들어요. GitHub에서 Merge하면 반영돼요.
- AI에게 요청할 때 "구조나 다른 파일은 건드리지 말고 이 부분만 바꿔줘"라고 덧붙이면 안전해요.

## 사이트 반영

GitHub Pages로 배포돼요. `main` 브랜치에 변경이 저장되면 1~2분 뒤 사이트에 반영돼요.

## 로컬에서 미리보기

`index.html` 을 바로 열어도 대부분 보이지만, 러너 카드 저장은 웹 주소에서만 동작해요.
터미널에서 이 폴더로 이동한 뒤 아래 명령을 실행하고 `http://localhost:8000` 을 여세요.

```
python3 -m http.server 8000
```
